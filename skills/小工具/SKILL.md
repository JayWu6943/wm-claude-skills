# 小工具選單

總監不懂程式，全程用繁體中文、台灣口語，不講術語；不要一直問授權，選好就直接做到完。

## 有帶文字時（例如 `/小工具 我想找預約表單在哪`）

依內容判斷該用哪個工具，直接照那個工具的 SKILL.md 做，不用再問：

| 總監想做的事 | 用哪個 |
| --- | --- |
| 寫貼文、文案、口播稿、剪輯建議、官網畫面建議、SEO、讓 AI 推薦、加新員工 | `.claude/skills/員工/SKILL.md` |
| 某個功能、頁面、按鈕「在哪裡」「怎麼運作」 | `.claude/skills/找功能/SKILL.md` |
| 「改了會不會壞」「會牽動哪裡」、找沒在用的程式、看整體架構 | `.claude/skills/關係圖/SKILL.md` |
| 用照片做影片、短片、宣傳片 | `.claude/skills/做影片/SKILL.md` |
| 自己拍好的影片要剪、上字幕、配樂 | `.claude/skills/剪影片/SKILL.md` |
| IG：短影音腳本、貼文、輪播、限動、個人檔案健檢、每週計畫、留言、私訊、檢討 | `.claude/skills/IG經營/SKILL.md` |
| 某一頁好不好看、好不好用、上線前檢查 | `.claude/skills/設計健檢/SKILL.md` |

## 沒帶文字時（只打 `/小工具`）

用 AskUserQuestion 問一題（header：「小工具」）：「今天要用哪個小工具？」選項：

1. **AI 員工／IG 經營**：請員工寫文案、看官網、做 SEO，或用 IG 工具箱寫腳本、健檢、排每週計畫
2. **找功能**：問某個功能在官網的哪裡
3. **改前先查**：改東西之前，先查會牽動哪些頁面
4. **影片**：用照片做一支新的品牌短片，或把自己拍好的影片剪成能發的短片

總監選好後，讀對應的 SKILL.md，照它的「沒帶文字時」流程繼續。選「影片」的話，再用一句話問「是要用照片做新的，還是剪你自己拍好的影片？」，照回答走做影片或剪影片。

## 結尾

做完後用一句話提醒下次可以直接打的快捷指令，例如「下次可以直接打 `/找功能 預約表單`」。
