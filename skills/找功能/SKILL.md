# 找功能（專案地圖）

總監不懂程式，用繁體中文白話回答；這個工具**只查、不改任何檔案**。

## 先找到官網專案（不用跟總監報告這步）

預設查的是薇萌官網（GitHub：JayWu6943/wm-website）。

1. 目前資料夾就是官網（有 `app/(site)/` 和 `.trail/`）的話，直接用。
2. 不是的話，改用 `/home/user/wm-website`。
3. 那裡也沒有，就 `git clone https://github.com/JayWu6943/wm-website /home/user/wm-website`。

之後的指令都在官網資料夾裡執行。總監明說要查別的專案，就照他說的。

## 沒帶文字時（只打 `/找功能`）

用一句話問總監：「想找哪個功能？例如：預約表單、會員註冊、首頁的服務介紹。」拿到回答再繼續。

## 步驟

1. **確認地圖準備好（不用跟總監報告這步）：**
   - 沒有 `trail` 指令就先裝：`npm install -g @trailhq/trail-code`。
   - 執行 `trail build`，確保地圖是最新的。已經是最新的話，不到 1 秒就跑完。
2. **查地圖：** 程式裡多半是英文名稱，所以先把總監的說法翻成 2～3 組英文關鍵字（例如「預約表單」→ booking form、BookingClient），再查：
   - `trail ask "<關鍵字>" --source`：先用這個。
   - `trail callers <功能名稱>`：要知道誰會用到它、它又用到誰時再用。
   - `trail grep "<文字>"`：要找畫面上某段文字出現在哪時用。

   地圖答得出來就不要再一個個開檔案翻；真的不夠才讀檔案裡相關的那幾行。
3. **看經驗筆記：** 看 `.trail/learnings/` 裡和這個功能有關的經驗筆記，有的話一定要告訴總監。例如預約表單規定一律繁體中文。
4. **回答（白話）：**
   - **在哪裡：** 哪個頁面、哪個檔案、大約第幾行。
   - **怎麼運作：** 用 2～4 句話說明，例如「按下送出後，會先檢查欄位，再把資料存進資料庫，並通知小薇」。
   - **相關的規則或注意事項。**
   - **最後一句：** 「如果要改這裡，可以先打 `/關係圖 改前先查 OO`，看看會牽動哪些頁面。」

## 不要做

- 不修改、不刪除、不新增任何檔案。
- 不貼大段程式碼給總監看，除非他要求。
