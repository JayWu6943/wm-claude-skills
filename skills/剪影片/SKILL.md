# 剪影片（短影片後製工作流）

老闆不懂程式，全程用繁體中文、台灣口語，不講術語；不要一直問授權。只有三個地方要停下來等老闆：
1. **剪輯表**：剪掉哪些、留下哪些，先給老闆看。
2. **第一版成片**：給老闆看，改到滿意為止。
3. **要花錢時**：先問老闆。

和 `/做影片` 的差別：`/做影片` 是用照片和一句話「做」一支新片；這裡是把老闆**自己拍好的影片**「剪」成能發的短片。

剪輯一律走影片製作團隊（OpenMontage）的流程和工具，**不可以**自己用 ffmpeg 拼一支交差。唯一的例外是最後「中文字幕燒進影片」那一步，原因寫在下面的製作順序裡。

## 後製流程總覽

| 站 | 做什麼 | 要不要停下來 |
| --- | --- | --- |
| 1. 收片 | 下載影片、看長度、直的還是橫的、有沒有聲音 | 不用 |
| 2. 聽打 | 把講的話轉成繁體中文逐字稿，校正專有名詞；有人帶著講時，分出每句是誰講的 | 不用 |
| 3. 粗剪 | 剪掉停頓、口誤、重講、「嗯啊那個」、引導的人講的話 | **停：給老闆看剪輯表** |
| 4. 精剪 | 開頭三秒放最抓人的一句、節奏收緊、轉成直式 | 不用 |
| 5. 調光調色 | 亮度、膚色自然，不過度磨皮 | 不用 |
| 6. 聲音 | 去雜音、音量拉平 | 不用 |
| 7. 字幕包裝 | 繁中字幕、重點字上色、片頭標題、片尾字卡 | 不用 |
| 8. 配樂 | 選好的音樂墊在人聲底下 | 選曲在第 3 站一起問 |
| 9. 品管 | 抽畫面檢查字、臉、聲音 | 不用 |
| 10. 交片 | 傳成片＋封面，請 TikTok 經營師寫發文文字 | **停：給老闆看第一版** |

## 0. 準備 OpenMontage

第一次會比較久，先告訴老闆「第一次要準備剪片工具，大約 5～10 分鐘」。

1. 先找 `$HOME/OpenMontage` 或 `/home/user/OpenMontage`，有就用。
2. 沒有的話，**只能**從官方下載：
   - `git clone https://github.com/calesthio/OpenMontage`，再進資料夾跑 `make setup`。
   - 網路上有冒名的版本會附 .exe、.7z「安裝檔」，那些是假的，絕對不要下載或執行。
3. `make setup` 沒裝到的，補裝：
   - 聽打和簡轉繁：`.venv/bin/python -m pip install faster-whisper opencc-python-reimplemented`
   - 字幕字體（思源黑體粗體）：放到 `~/.fonts/NotoSansTC-Bold.ttf`，再跑 `fc-cache -f`。
     下載網址從 `curl -s 'https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@700' -A 'Mozilla/4.0'` 回傳內容裡的 `.ttf` 連結取得。GitHub 上的字體檔這台電腦抓不到，不要用。
4. 開工前先讀它的 `AGENT_GUIDE.md`、`CLAUDE.md`，還有選到的流程在 `skills/pipelines/<流程>/` 底下的說明，照它的關卡走。
5. 工具的叫法：`from tools.<類別>.<檔名> import <名稱>`，再呼叫 `.execute({...})`。這支流程會用到：
   - `tools.analysis.transcriber` 的 `Transcriber`：聽打
   - `tools.video.silence_cutter` 的 `SilenceCutter`：找停頓
   - `tools.video.auto_reframe` 的 `AutoReframe`：轉直式
   - `tools.video.video_compose` 的 `VideoCompose`：剪接
   - `tools.enhancement.color_grade` 的 `ColorGrade`：調色
   - `tools.audio.audio_enhance` 的 `AudioEnhance`：聲音
   - `tools.audio.audio_mixer` 的 `AudioMixer`：配樂

## 1. 收片

### 拿到影片

老闆沒給影片的話，用一句話告訴他兩種給法：
- **雲端硬碟（建議，影片大也沒問題）：**
  1. 把影片放進 Google 雲端硬碟的一個資料夾。
  2. 資料夾按「共用」，改成「知道連結的任何人都能檢視」。
  3. 把連結貼給我。
- **直接傳到對話裡**：適合一兩分鐘的小檔案。

下載方式：
- **資料夾連結：** 用 Google 雲端硬碟工具列出資料夾裡的影片。
- **每個檔案：** 用 `https://drive.usercontent.google.com/download?id=<檔案編號>&export=download&confirm=t` 下載。
- **下載失敗：** 通常是沒開「知道連結的任何人」，請老闆改共用設定。
- **存放位置：** 影片放到 OpenMontage 的 `projects/<片名英文代號>/inputs/`。每支新片開新的專案資料夾，不要蓋掉舊的。

### 問清楚要什麼

老闆已經說清楚的就不要再問。沒說的，用**一次** AskUserQuestion 問完，最多 4 題：

| header | 問題 | 選項 |
| --- | --- | --- |
| 片型 | 這支影片是哪一種？ | 對著鏡頭講話／一段長的要切成好幾支短片／沒講話的畫面配音樂（花絮、活動） |
| 出鏡 | 影片裡講話的是誰？ | 老闆（歐巴老吳）／主管（萌主）／兩個人都有／其他人或沒人講話 |
| 長度 | 成片大概多長？ | 30 秒內／60 秒內／90 秒內／照內容決定 |
| 拍法 | 拍的時候有人在旁邊先講一句、出鏡的人再跟著講嗎？ | 有，旁邊有人帶著講／沒有，出鏡的人自己講 |

平台不用問：成片一律做直式 9:16，IG、臉書、TikTok、YouTube 短影片都能直接發。

片型對應的流程（在 `pipeline_defs/`）：

| 片型 | 流程 |
| --- | --- |
| 對著鏡頭講話 | `talking-head` |
| 一段長的要切成好幾支短片 | `clip-factory` |
| 沒講話的畫面配音樂 | `documentary-montage`，畫面偏氛圍、情緒的用 `cinematic` |

## 2. 聽打

1. 用聽打工具轉逐字稿，語言設 `zh`：
   - 影片 10 分鐘內用 `medium` 模型，比較準；更長的用 `small`。
   - 聽打在這台電腦上跑，不用錢。
   - 第一次要先下載模型，多等幾分鐘；之後一分鐘的影片大約聽打 1～2 分鐘。先跟老闆說大概要等多久。
2. 用 OpenCC 的 `s2twp` 把逐字稿轉成台灣繁體用字。
3. 校正逐字稿。聽打常會聽錯同音字（例如把「依照」聽成「一照」），要照上下文改回來：
   - 固定要對的字：薇萌、WM Group、形象照、品牌形象照、企業形象照、萌主、歐巴老吳、身分（不是「身份」）。
   - 猜不出來的字，列出來第 3 站一起問老闆。

### 有人帶著講時：分辨每句是誰講的

「拍法」選「有人帶著講」，或聽打後發現同一句話隔幾秒又出現一次，就要做這一步。

1. 跑這個資料夾的 `誰在講.py`，標出每一句是「引導」還是「出鏡」：
   `.venv/bin/python <這個資料夾>/誰在講.py 逐字稿.json 原片.mp4 誰在講.json`
2. 它怎麼判斷：
   - **跟讀配對：** 一句話幾秒內又出現一次，前面那句是引導的人，後面的是出鏡的人。
   - **聲音高低：** 把聲音分成兩群，例如一個人聲音低、一個人聲音高。沒有跟著重講的提示話，例如「好，再來一次」「笑一下」，也能分出是誰講的。
   - 兩種判斷對不起來，或聲音太像分不開的，會標「不確定」。
3. **剪的規則：**
   - 標「引導」的句子全部剪掉。
   - 同一句出鏡的人講了好幾次，留講得最順、表情最好的那一次，其他次剪掉。
   - 「不確定」的句子在剪輯表裡標出來，請老闆確認。
4. **不要做：** 不要用聽打工具的 `diarize` 選項分辨說話的人，它要另外申請帳號。用 `誰在講.py` 就好。

## 3. 粗剪：做剪輯表，給老闆看

用找停頓工具（`mode: "mark"`，只標記不剪）找出停頓，再對照逐字稿判斷：
- **要剪掉：**
  - 超過 0.5 秒的停頓。
  - 口誤，以及講錯重講的那一次（留講得好的那次）。
  - 「嗯、啊、那個、就是」這類贅字。只剪停頓剪不掉它們，一定要看逐字稿挑出來。
  - 開頭準備和結尾關機的畫面。
- **開頭三秒：** 挑整支裡最抓人的一句話或一個問題，建議移到最前面當開頭。
- 剪完超過老闆要的長度，就列出可以拿掉的段落。

用條列給老闆看，不要出現時間碼以外的技術字：

```
剪輯表（原片 2 分 40 秒 → 預計 58 秒）
開頭：「你知道證件照跟形象照差在哪嗎？」（原本在 1:12，移到最前面）
保留：0:05～0:31 介紹三種照片的差別
剪掉：0:31～0:38 講錯重講
剪掉：0:38～0:41 引導的人帶的那句
不確定：0:52～0:54「好 再來」是誰講的？（目前先剪掉）
保留：0:38～1:10 ……
片尾：品牌字卡 3 秒
配樂：（三首選項，見下方）
要確認的字：「XX」是不是「OO」？
```

**配樂選項一起給：**
- **來源：** 從 Epidemic Sound 或 Artlist 的曲庫挑 3 首適合的，用一句話形容各首的感覺，例如「輕快鋼琴、有溫度」。
- **要花額度：** 下載會用掉額度的話，先講清楚。
- **其他選項：** 也可以選「不要音樂」，或用老闆自己提供的曲子。

再用 AskUserQuestion 問（header：「剪輯表」），選項：
- 照這樣剪
- 我要修改

## 4～9. 精剪到品管

照 OpenMontage 該流程的關卡做完，下面是薇萌的固定規格。

### 製作順序（實測過可用）

1. **轉直式：** 原片是橫的，先用 `AutoReframe`（`target_aspect: "portrait"`）轉成 1080×1920。轉直式不會改時間，剪輯表的時間照用。
2. **剪接：** 把剪輯表「保留」的段落排成 `cuts`，用 `VideoCompose` 的 `operation: "compose"` 一次剪好。
   - **一定要加 `profile: "instagram_reels"`**，不然會被改回橫的 1920×1080。
   - 不要用 `video_trimmer` 的 concat，它剪不準，會差好幾秒。
3. **調色：** `ColorGrade`，`profile: "bright_clean"`，`intensity: 0.5`。
4. **聲音：** `AudioEnhance`，`preset: "clean_speech"`。
5. **配樂：** 有選音樂的話，用 `AudioMixer` 墊在人聲底下，講話時自動壓低。
6. **片尾：** 畫面最後一格延長 3 秒，聲音補 3 秒靜音，給片尾字卡用。
7. **重新聽打成片：** 剪過以後時間都變了，要對成片重聽一次，才拿得到準確的字幕時間。字用第 2 站校對好的，不要用重聽的。
8. **字幕：** 照下面的字幕規格做成字幕稿 JSON，用這個資料夾的 `字幕.py` 轉成字幕檔，再燒進影片。
   - 為什麼不用 OpenMontage 的字幕：它內建的逐字字幕是為英文設計的，中文字中間會多出空格，所以中文字幕一律走這支。
   - 燒進去時順便把音量拉到平台標準：`ffmpeg -i 成片.mp4 -vf "subtitles=字幕.ass:fontsdir=$HOME/.fonts" -af loudnorm=I=-14:TP=-1.5 -c:v libx264 -crf 18 -c:a aac 輸出.mp4`

### 畫面

- **尺寸：** 直式 9:16、1080×1920。橫的原片用自動追臉轉直式（auto_reframe）。
- **調色：** 膚色自然、略暖。磨皮和眼周修飾只能用很輕的強度。老闆是拍形象照的，過度修圖會傷招牌。
- **節奏：** 30 秒以上的片，每 3～5 秒要有一點變化，例如稍微放大、換角度或跳出重點字。不要每一刀都放大縮小，會讓人看了頭暈。

### 聲音

- 先去雜音，再把整支的音量拉平。
- 配樂墊在人聲底下，講話時要自動壓低，聽得清楚人聲最重要。

### 字幕

- **用字：** 繁體中文。
- **字體：** 思源黑體（Noto Sans TC）粗體，白字加深色描邊。
- **長度：** 一行最多 12 個字，一次最多兩行。
- **位置：** 放在畫面高度約 65%～75% 的地方。最下面 20% 會被平台的按鈕和說明文字擋住，不要放字；也不要蓋到臉。
- **重點字：** 每句挑 1～2 個重點字用品牌金色 `#C9A77C` 標出來。
- **標點：** 不加句號，逗號改成空格。

### 片頭和片尾

- **片頭標題：** 前 3 秒在上方放一行標題（12 字內），內容就是這支片在講什麼。
- **片尾字卡：** 2～3 秒，照「出鏡」那題選的人用下面的設定。兩個人的設定一律分開，不要混用。

| | 老闆（歐巴老吳） | 主管（萌主） |
| --- | --- | --- |
| 署名 | 歐巴老吳｜薇萌 WM Group | 萌主｜薇萌 WM Group |
| 片尾一句話 | 想拍出你的專業形象，私訊我們 | 想拍出你的專業形象，私訊我們 |
| 網址 | wmgroup.com.tw | wmgroup.com.tw |

- **兩個人都有：** 用老闆的那一欄。
- **其他人或沒人講話：** 署名只寫「薇萌 WM Group」。
- **老闆說要改：** 直接改這張表，並照「上傳」那段把改好的版本存回去。

### 品管

1. 抽 4～6 格畫面看：
   - 字有沒有缺、有沒有被切掉、有沒有蓋到臉。
   - 繁體字對不對。
   - 片尾字卡對不對人。
2. 聽開頭、中間、結尾各 5 秒：人聲清楚、音樂不搶、沒有爆音。
3. 有問題就修好重新輸出，品管過了才給老闆。

## 10. 交片

1. 用 SendUserFile 傳給老闆：
   - 成片
   - 一張封面圖：從前 3 秒片頭標題還在的時候，挑一格表情好的畫面截下來
2. 用 Agent 工具請「TikTok 經營師」寫發文文字，交代時一定加上：
   - 用繁體中文、台灣口語。
   - 對象是薇萌 WM Group（形象照、品牌影像、保險理財、行銷顧問）。
   - 只寫草稿，不要發布。
   - 附上剪好的逐字稿。

   請他交回：
   - 3 個標題選項
   - 一段貼文文字
   - 5～8 個標籤
   - 封面字建議
   - 建議發布時段（數字是推估的要標出來）
3. **回報給老闆：**
   - 長度和尺寸。
   - 花了多少錢：外部服務費，加上大約的 Claude 用量。
   - 整理好 TikTok 經營師寫的發文文字，標明是他寫的。
4. **提醒：**
   - 這台電腦在對話結束後會清空，成片請先存到手機或雲端硬碟。
   - 影片裡有客人入鏡的話，發布前要先確認客人同意。
   - 內容講到保險、理財的，發布前請老闆自己再確認一次說法。
5. **最後一句：** 「要改哪裡直接說，例如『開頭那句字放大』『第二段剪掉』」。

## 不要做

- 不從官方以外的地方下載 OpenMontage 或任何「安裝檔」。
- 不在老闆沒同意的情況下用付費服務，包括 AI 配音、AI 生畫面、會扣額度的音樂下載。
- 不把老闆的原片、成片、OpenMontage 的專案檔上傳到官網的 GitHub。影片只交付給老闆。
- 不替老闆發布到任何平台。
