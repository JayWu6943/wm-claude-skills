# 一變多：一支長影片或文章 → 一週的短影音和輪播

一個好的長內容裡面有四到六篇貼文，大部分人只拿出一篇，其他都丟了。

## 要的資料
逐字稿、文章、電子報、腳本、會議摘要、直播。
- 對方給網址，而這次對話有聽打工具，就用；沒有就請他貼上。
- 全部讀完才開始挑。
- 來源是他自己的影片，請他也給影片檔：用他自己的畫面剪的短影音，勝過把他講過的話重念一次。這部分交給 `/剪影片`。

## 是「挑出來」，不是「做摘要」
影片的摘要不是短影音，沒有人想看摘要。從頭到尾挑出能單獨成立的東西：

| 挑什麼 | 是什麼 |
| --- | --- |
| 主張 | 每一句會引起爭論的話 |
| 數字 | 每一個數字、費用、時間、百分比 |
| 故事 | 每一個有人、有場景、有代價的片段 |
| 原理 | 每一個「其實它是這樣運作的」 |
| 出包 | 每一個承認做錯的地方 |
| 金句 | 每一句原本就能直接引用的話 |

先列出找到什麼、各有幾個，再開始寫。挑不到四個，代表這個來源很薄，硬擠出四篇也會很薄，直說。

## 每一個挑出來的東西，選格式
不是每個都做短影音：
- **主張、出包、故事 → 短影音。** 需要聲音和臉。
- **原理、清單 → 輪播。** 需要重看。
- **金句 → 一則限時動態**，不是一篇貼文。

## 排成一週
- 每一篇都要完全獨立。觀眾沒看過原始影片，以後也不會看，絕不寫「就像我上一支影片說的」。
- 每一篇從 `開頭公式.json` 配一個公式，而且要不同。五篇都同一種開頭，看起來就像內容工廠。
- 來源是他自己的影片，**用真的畫面**：他講那句話的片段，連真實的反應一起，勝過重拍。剪在句子上，不要剪在換氣上。
- 順序：最強的主張放第一篇，故事放週中，原理放最後，留給前面看過、在等下一篇的人。

## 交出來
```
來源：「為什麼我們不再接 APP 案」（42 分鐘訪談，8,900 字）
找到：主張 5、數字 9、故事 3、原理 4、出包 2、金句 7
這週
二  短影音  #2 反向指令    別再一開始就做 APP
                          用 14:20 那段，他最後有笑
三  輪播    任務 B 貼文     取代 APP 的四步驟表單
五  短影音  #21 從中間開始  「……結果他九天後要求退款」
日  短影音  #5 時間壓縮    每週省回六小時，只刪了一個連結
說「寫星期二」，我就幫你寫。
```
對方要了，才一篇一篇寫，每篇走「短影音腳本」或「輪播」的流程。不要一次丟四篇寫好的腳本，聽起來都會一樣，結果一篇都不會拍。
