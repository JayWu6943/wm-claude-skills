# 成效檢討：從自己發過的貼文，找出什麼真的有效

一個帳號什麼有效，唯一誠實的來源是這個帳號自己。所有 IG 教學裡的規則，包括這個工具箱的，都只是「預設」；最近 30 篇才是證據。

## 要的資料
對方有什麼就給什麼：
- **每篇的數據**：觀看、觸及、互動、觀看時間、收藏、分享、追蹤，以及非追蹤者的觸及比例。截圖就可以。
- **或是最好和最差幾支短影音的觀看留存曲線。** 這一張截圖比其他加起來都有用。
- **或是只有貼文和觀看數**：做第一次檢討夠了。

也讀這個人的 `發文紀錄.md`（有的話），裡面記了每篇用的開頭公式。

## 真正要算的數字
觀看數是最沒用的數字，因為它主要取決於已經有多少人追蹤。改算這些，並把算法列出來：

| 數字 | 怎麼算 | 告訴你什麼 |
| --- | --- | --- |
| 倍數 | 觀看 ÷ 這個帳號觀看的中位數 | 是真的紅了，還是普通的一天 |
| 非追蹤者觸及 | 觸及裡來自沒追蹤的人的比例 | 有沒有傳出去 |
| 3 秒留存 | 3 秒時還在的人 ÷ 開始看的人 | 開頭有沒有用。這是開頭的成績單 |
| 平均觀看時間 | 數據裡直接看 | 中段有沒有用 |
| 分享率 | 分享 ÷ 觸及 | 最強的訊號。分享代表有人願意掛自己的名字推薦 |
| 追蹤率 | 追蹤 ÷ 觸及 | 個人檔案有沒有把注意力變成追蹤 |

用倍數和分享率排名，不用觀看數。4,000 觀看、90 次分享的那支，贏過 60,000 觀看、11 次分享的那支。

## 找出模式
最好五篇和最差五篇並排，找出差別。要願意下對方不愛聽的結論：
- **3 秒留存**：好的和差的差在這裡，就是開頭的問題，其他都是枝節。
- **開頭公式**：前五名用了 `開頭公式.json` 的哪幾個？
- **格式**：短影音、輪播、單張。
- **長度**：分成 15 秒以下、15～30 秒、30～60 秒、60 秒以上。
- **主題**。
- **第一個小時有沒有回留言**。
- **星期幾和幾點**：**最後**才看，而且只在其他都看不出東西時才看。它幾乎從來不是原因，偏偏大家最想怪它。

結論要寫成一個主張，附上證據，說明有多少把握。30 篇看得出模式；6 篇看不出來，直說比硬編一個好。

## 可以省下幾個月的區分
- **有觀看、沒追蹤的影片，不是失敗的影片，是個人檔案的問題。**
- **沒觀看的影片，是開頭的問題。**

先分清楚這兩種再給建議。非追蹤者觸及高、追蹤率低，就不要再改開頭了，去做「個人檔案健檢」。

## 交出來
```

倍數前 5 名
  18.2 倍  #3 沒人告訴你  74,600 觀看  非追蹤 62%  3 秒留存 71%  分享 128
   6.4 倍  #1 代價告白    26,300 觀看  非追蹤 48%  3 秒留存 64%  分享 71
  ...
最後 5 名
   0.3 倍  #11 清單加私心  1,200 觀看  非追蹤 9%  3 秒留存 31%  分享 2
  ...
數據說
1. 3 秒留存就是全部。前五名平均 66%，後五名 33%。你擔心的其他事都在前兩秒之後。
2. 你自己出糗的那幾篇：平均 8.1 倍，其他平均 0.9 倍（5 篇）。這是最強的訊號，差很多。
3. 工具清單類只有觀看，沒有分享、沒有追蹤，後五名裡有三篇是這種。
4. 星期幾看不出差別，星期二和星期五的平均在誤差範圍內。不用再研究了。
停止：工具清單類
多做：自己付過代價、有數字的那種
```
最後把結論交給「每週計畫」，下週照自己的證據排；也交給「爆款研究」，參考清單只留對這個帳號有效的公式。總監和主管分開檢討、分開存。
