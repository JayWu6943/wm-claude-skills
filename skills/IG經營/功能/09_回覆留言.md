# 回覆自己貼文底下的留言

觸及是在自己貼文的留言區決定的。每則回覆都是一次互動，第一個小時內的回覆效果最大。IG 的回覆也可以是一支短影音，這是最被低估的一招。

但每則留言的價值不一樣，所以這個功能先分類，再寫回覆。

## 要的資料
請對方貼上留言，最好有帳號名稱，截圖也可以。不用瀏覽器去抓留言區。

## 先分類
每則留言分到六類之一，並說出各有幾則：

| 類別 | 是什麼 | 怎麼回 |
| --- | --- | --- |
| 關鍵字 | 留了你要他們留的那個詞 | 把承諾的東西給他，手動或用核准的工具 |
| 潛在客戶 | 描述的問題剛好是你能解決的 | 公開給一個真的回答，最後開一扇門 |
| 有料 | 補數據、不同意、延伸 | 整串裡最長的回覆 |
| 好問題 | 很多人都會有的問題 | 這則要變成一支短影音，不只是回覆 |
| 支持 | 「🔥」「好讚」、標朋友 | 按愛心，回 3～10 個字就好 |
| 雜訊 | 推銷、廣告、來亂的 | 不回，或一句就走 |

照這個順序寫，價值沒了就停。

## 大部分人不知道的一招
留言區有個問題是另外三十個人也會想問的，就**用一支短影音回覆它**：IG 會把那則留言當貼紙放在新影片上，發問的人會收到通知。一個真的有需求的問題，就變成一支開頭已經寫好的影片。

把符合的「好問題」都標出來，交給「短影音腳本」，用公式 #16「照抄問題」。

## 怎麼回
- **回答他真正問的。** 問怎麼做就在回覆裡說怎麼做，不要叫他私訊才告訴他。
- **開頭叫一次他的名字**，不加驚嘆號。
- **長度跟他差不多。** 四個字的留言，不用回四行。
- **對批評的人**：先用他的話承認對的部分，再堅持立場。不刪留言、不防衛、同一串不回第二次。
- **對來亂的人**：不回。回覆就是給他曝光，他就是為這個來的。太過分就用 IG 的留言管理隱藏，這不叫輸。
- **對潛在客戶**：公開完整回答，最後一句開一扇門，是提供幫忙，不是推銷。例如邀請加 LINE 官方帳號拿資料。公開的回答會讓下一個人主動私訊你。

## 關鍵字留言
貼文用了「留言關鍵字」，這些留言就是整篇貼文的目的，每一個都是舉手的人。
- 每則都回，再把承諾的東西傳給他。
- 有用 IG 官方工具或核准合作夥伴設好自動回覆的話，說一聲，讓它跑。沒有的話就手動，這個量手動沒問題。
- 絕不私訊沒有留言的人。

## 交出來
一個區塊，照類別分組，每則回覆都能直接複製，先跑 `去AI味.py`。
```
回覆 · 84 則留言 · 關鍵字 41、潛在客戶 2、有料 3、好問題 2、支持 34、雜訊 2
關鍵字（41）  傳條款。每則一句，同樣的溫度，但不要複製貼上。
潛在客戶
@帳號 —「我們六月也發生一模一樣的事」
> 我們後來是把付款條件從「滿意」改成「交件」才解決的。需要的話我把那段文字傳給你。
好問題 → 拍成短影音
@帳號 —「客人不肯簽怎麼辦？」
  這則有 34 個愛心，這是一支短影音，不只是回覆。公式 #16。
雜訊（2）  不回，回了等於幫他曝光。
```
等對方說好才算數，不代發，由本人貼上。
