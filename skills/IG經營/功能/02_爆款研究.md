# 爆款研究：找出同領域現在真的有效的影片，整理成參考清單

這個功能是去「看」，其他功能是「寫」。一個月做一次就好，公式大約一季就會換。

## 最重要的觀念：觀看數本身不是證據
兩百萬粉絲的帳號拿到四十萬觀看，只是普通的一天。四千粉絲的帳號拿到四十萬觀看，是真的做對了什麼，而且學得來。

所以一律用**倍數**排名：倍數 = 這支的觀看數 ÷ 這個帳號最近影片觀看數的中位數。
- 3 倍以上才算訊號。
- 1.5 倍以下只是那個帳號的日常，學不到東西。

挑**跟自己帳號大小差不多（10 倍以內）**的帳號。在兩百萬粉絲才有效的做法，往往是因為他有兩百萬粉絲。

## 步驟 1：挑帳號
請對方給 6～12 個帳號，或你提案給他同意：
- **4 個同行**：同領域、同服務、比你稍微領先。例如其他形象照工作室、企業攝影、個人品牌顧問。
- **4 個相鄰**：不同領域、同一群觀眾。新的形式常常先從這裡借來，同行還沒人用。例如：保險業務、房仲、診所醫師、創業者的帳號。
- **2～4 個大帳號**：只看形式，不學頻率和語氣。

也請對方打開自己 IG 的「**收藏**」：那是最快、最相關的素材，而且已經照他的品味篩過了。

## 步驟 2：去看
用這次對話有的瀏覽工具（內建瀏覽器、連到對方自己 Chrome 的擴充功能）。

**不能破的規則：**
- **絕不代為登入 IG、絕不問密碼。** 要登入的頁面，請對方自己開好，或請他貼上來。
- **是「看」不是「爬」。** 10 個帳號、每個看十幾支，用人的速度看。大量自動抓取違反 IG 規定，會被限制帳號。不寫爬蟲、不用抓資料的服務、不在背景一直跑。
- **學公式，不抄影片。** 學開頭的句型、結構、長度、剪接節奏；不抄他的腳本、語氣、剪輯。參考清單每一列都標明來自哪個帳號。

**每支要記下來的（用原文）：**

| 欄位 | 說明 |
| --- | --- |
| 帳號 | @名稱 |
| 粉絲數 | 個人頁上的 |
| 中位數 | 看他最近 12 支的觀看數，取中間那個 |
| 觀看數 | 這支的 |
| 開頭 | 第一句話或第一行畫面字，照原文，文法不對也照抄 |

中位數最重要，沒有它就又回到用粉絲數排名，這正是這個功能要避免的。

**IG 看不到足夠資料時**：同樣的開頭句型也在 YouTube 短影音上跑，觀看數公開、不用登入，可以當第二來源。

## 步驟 3：排名
填成 Tab 分隔的表格，第一行是欄位名稱：
```
帳號	粉絲數	中位數	觀看數	開頭
@someone	48000	11000	412000	沒有人會告訴你，你的前三十支影片本來就會失敗
```
跑：`python 爆款排名.py 蒐集.tsv --out ~/.claude/instagram/總監/參考清單.md`（主管就存到主管的資料夾）

它會算倍數、標出開頭用了哪個公式、替每個開頭打分，再整理 3 倍以上那些的共同點。

## 步驟 4：說結論，要小心
只講三件事：
1. **哪些公式在前三分之一特別多**，附次數。兩個公式在六個帳號裡各出現四次，算發現；一個出現兩次，不算。
2. **前三分之一有、後三分之一沒有的結構差異**：開頭長度、成果是不是畫面看得到、第一格有沒有動、行動呼籲放在哪。
3. **認不出公式的那些**：要嘛是雜訊，要嘛是 `開頭公式.json` 還沒有的新公式。一個一個看，這是最有價值的一欄。

最後用白話講樣本數和把握程度：六個帳號四十支，可以下結論；十二支就不行，要直說。

## 步驟 5：變成能拍的東西
前三名的公式，各寫一個**自己的版本**：用他自己的故事、他自己的數字，套進這個有效的形式。帶著公式編號交給「短影音腳本」。

不要交回「拍一支像這樣的」。要交回一句他明天就能講的開頭。

參考清單存到那個人的 `參考清單.md`，之後「短影音腳本」和「每週計畫」都會讀。

這個功能不發文、不追蹤、不按讚、不私訊。只看。
