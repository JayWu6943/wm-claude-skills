# 短影音腳本：一個點子 → 有人會看完的短影音

## 開始前
1. **確認是誰的帳號**，讀那個人的 `語氣.md`：他在鏡頭前怎麼講話、絕對不講的話、在對誰講。
   - 沒有這份檔案的話，請對方給三支自己的影片或貼文，讀完推敲出語氣，照 `語氣設定範本.md` 寫好再開始。
   - 腳本語氣不對，就不能用，因為要自己講出來。
2. **讀 `開頭公式.json`**：26 種公式，每個都有句型、範例、畫面字、適合用在哪、常見地雷。
3. **點子太薄就不要硬寫。** 一次問清楚：發生了什麼事、發生在誰身上、付出了什麼代價或得到什麼回報。一支短影音需要一件具體、真實的事。
4. **有 `參考清單.md` 的話一定要讀**：那是爆款研究整理出來、這個帳號領域裡現在有效的公式，比預設值更準。

## 結構
```
0～2 秒    開頭      講的那句和畫面字分開寫。第一格就要有動作或字，不要只有一張不動的臉
2～7 秒    為什麼重要  跟觀眾有什麼關係，一句話
7 秒之後   內容      一句一個重點，每句畫面都要有變化
最後 3 秒  兌現      兌現開頭的承諾，再給「一個」行動呼籲
最後一句   呼應      重複開頭的一個詞，觀眾比較會重看
```
長度：15～45 秒最好用。短影音可以到 3 分鐘，但幾乎沒人需要。

## 步驟
1. **挑三個開頭，不是一個。**
   - 從 `開頭公式.json` 挑三個真的適合的公式，每個都寫「講的那句」和「畫面字」。
   - 三個要是不同公式，不是同一句改三次。
   - 交給內容企劃師寫初稿，TikTok 經營師修開頭。
2. **打分數。** 三句講的開頭放進檔案，一行一句，跑 `python 開頭評分.py 開頭.txt`，把排名給對方看。最高的不到 50 分，就是還沒有好開頭，重想一輪。
3. **寫腳本。** 用最高分的開頭。白話、短句、照他平常講話的方式，不要有需要背的句子。
4. **算秒數。** 跑 `python 秒數表.py 腳本.txt --target 秒數`（主管講話速度不同，加 `--rate`）。每個提醒都要處理：
   - 開頭超過 3 秒
   - 某句超過 4 秒
   - 連續三句沒有具體內容
   - 結尾沒呼應開頭
   
   改完再跑，直到乾淨。
5. **去 AI 味**：交出來前先跑 `python 去AI味.py 腳本.txt`。寫出來像文章的句子，講出來馬上聽得出來。
6. **交出來：**
   - 腳本（一個區塊）
   - 畫面字清單，標時間
   - 摘要：

   ```
   腳本完成
   開頭：#3 沒人告訴你，86 分（強）
   長度：約 28 秒，9 句（每秒 4.8 字）
   畫面字：6 張
   貼文文字：下一步可以做「貼文文字」
   ```
7. **不代發。** 對方說「好」，就在 `發文紀錄.md` 記下日期、用的公式、開頭那句，之後「成效檢討」用得到。

## 畫面字是另一份腳本
- **一張最多 8 個字。** 觀眾還沒開聲音就先看到字。
- **開頭那張字第 1 格就要出現。**
- **安全範圍**：1080×1920 的畫面，字不要放在最上面 230 像素、最下面 480 像素（也就是 1440 以下），右邊 230 像素也要空著。這些地方會被平台的按鈕、說明文字蓋住。
- **內容段落要有字幕**：多數人一開始是靜音看。

## 讓差別出來的規則
- **一支只講一件事。** 腳本裡有兩件事，就是兩支影片，直接說。
- **數字勝過形容詞。** 「三萬塊」勝過「很多錢」。對方沒給數字就問，不要繞過去。
- **砍掉開場。** 不打招呼、不說「這支影片要…」、不報名字。從平常第 6 秒才講到的那句開始。
- **每句畫面都要變**：換角度、跳字、放大。停 8 秒不動的畫面，觀眾就滑走了。
- **結尾只有一個動作**：留言關鍵字、收藏、追蹤、私訊，選一個。
- **不編造**：不知道的數字留 `{{你的數字}}`。
- **剪片時**：拍完交給 `/剪影片`。腳本可以一起給，字幕會更準，藏鏡人的提問也分得更準。
