# 限時動態：讓已經追蹤的人決定要不要跟你買

限時動態不是縮小版的貼文。貼文是讓陌生人找到你；限時動態是讓已經追蹤你的人決定你值不值得買，而且是 IG 上唯一一個點一下就能變成對話的地方。

只有追蹤的人看得到，所以任務完全不同：要深度，不要觸及。

## 每天的形狀：3～7 則
超過 7 則，跳過的人變多，最後幾則根本沒人看，偏偏大家都把行動呼籲放在最後。
```
第 1 則     開場   今天正在發生的事，畫面要有臉或手
第 2～3 則  中段   真正的內容：過程、成果、出的包
第 4 則     互動   一個貼圖：投票、問答框、測驗、連結
第 5 則     收尾   答案、結果，或預告明天
```
互動放第 4 則，不要放第 7 則。

## 貼圖和它們真正的用途

| 貼圖 | 用途 | 什麼時候用 |
| --- | --- | --- |
| 投票 | 最便宜的一下點擊 | 想要很多人回應，不需要資訊 |
| 問答框 | 收集觀眾的原話 | 需要內容點子或客人的疑慮，原文照收 |
| 測驗 | 讓他們先答錯再學會 | 這個領域有常見的誤解 |
| 滑桿 | 看看大家的感覺 | 不重要，好玩而已 |
| 連結 | 個人檔案以外唯一能點的地方 | 有真的要去的地方，例如預約頁、LINE 官方帳號 |
| 倒數 | 讓人可以訂閱的期限 | 新方案、直播、截止日 |
| 加入你的 | 偶爾觸及到追蹤者以外的人 | 題目是同領域任何人都能回答的 |

**問答框是最被低估的。** 每個回答都是一篇貼文文字、一個短影音開頭、或一個私訊開場，而且是觀眾自己的話。交給「短影音腳本」，用公式 #16「照抄問題」。

## 規則
- **第一則要有臉或手。** 純色背景加字會被直接跳過，第一則決定後面有沒有人看。
- **一則一個重點。** 沒有人會在限時動態裡讀一段文字。
- **字放在中間。** 1080×1920 的畫面，最上面 250 像素、1600 以下不要放字，那裡有大頭貼列和回覆框。
- **對一個人講話。** 用「你」。限時動態是最接近私訊的地方。
- **不要把自己的貼文原封不動轉到限時動態。** 那是全 IG 最常被跳過的一則。要轉，就說留言區發生了什麼、為什麼值得回去看。
- **在限時動態賣，不要在貼文賣。** 三則背景、一則方案、一則證明，比一篇講同一件事的貼文賣得更好，也不會掉觸及。

## 導到私訊，用正當的方式
有效的順序：
1. 一則點出問題的限時動態。
2. 一個問答框或投票，讓人說「我就是這樣」。
3. 回覆每一個有回應的人。

對話會開始，是因為對方先開口。

商業帳號用 IG 官方工具或核准的合作夥伴設定「關鍵字自動回覆」，是可以的。私訊沒有互動過的人，不行，會被限制帳號。原則很簡單：**對方先動，你再回。** 也可以在回覆裡邀請對方加 LINE 官方帳號。

## 交出來
每一則都寫：畫面是什麼、講什麼、用哪個貼圖。最後說明回答要怎麼處理。
```
限時動態 · 星期二 · 5 則
1 ［自拍、走路中］  「今年第三個客人要退款了，同一個原因。」
2 ［螢幕錄影］      合約那一句，畫重點
3 ［對鏡頭講］      「滿意是一種感覺，交件是一個日期。」
4 ［投票］          「你有沒有被晚付款坑過？」有／還沒
5 ［照片加字］      「回覆我，我把那句條款傳給你。」
之後：每個投「有」的人都回一則。整個流程就這樣。
```
不代發，對方自己發。
