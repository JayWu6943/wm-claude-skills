# 個人檔案健檢：100 分打分，照扣分多寡依序改

大部分人都優化錯東西。個人檔案不是讓人慢慢逛的店面，而是**做決定的畫面**：陌生人從一支短影音點進來，大約三秒內要回答一個問題：「這裡還有更多那種內容嗎？是給我的嗎？」

## 要的資料
請對方貼上或截圖：名稱欄、帳號、簡介、連結指到哪、精選動態的名稱、置頂了什麼、前九格封面。個人頁最上面的截圖，加上格子前兩排，就夠做第一次健檢。

不代為登入 IG。

## 打分
讀 `個人檔案評分表.json`：12 項、滿分 100，每項都寫了滿分長怎樣、常見錯誤。每一項都打，給出表格和總分。

要誠實，大部分第一次都在 30～40 幾分，太寬鬆的分數沒有用。
```
個人檔案分數 38/100
  名稱欄        2/12   只有名字，沒有任何別人會搜尋的詞
  簡介第一行     3/12   三個名詞加一杯咖啡的表情符號
  置頂三篇       0/10   沒有置頂
  精選動態       2/8    「日常」「隨手」「2023」
  格子好不好讀   4/8    九張封面裡六張是講話講到一半的臉
  ...
```

## 照扣分多寡依序改
不要一次全部改，對方要一個一個去改。

1. **名稱欄（30 字）**：粗體那行，不是帳號。這是 IG 搜尋會比對的欄位，大部分人只放名字。格式：`{名字}｜{你做什麼，用別人會搜尋的詞}`，給三個選項。例如：
   - 歐巴老吳｜企業形象照・品牌攝影
   - 萌主｜個人形象照・品牌顧問
2. **簡介第一行**：這是給誰的、會改變什麼。不是職稱，不是形容詞，不是一串直線隔開的身分。150 字裡剩下的放一個證明或一個具體方案。
3. **置頂三篇**：三個位置、三個任務：最好的證明、把方案講最清楚的、最能認識這個人的。這是整個檔案最划算的修改，按四下就好。
4. **精選動態**：4～6 個，用客人會問的問題命名：價格、作品、流程、關於我。其他的刪掉。
5. **連結**：一個去處，跟簡介承諾的事對得上，例如預約頁或 LINE 官方帳號。可以放 5 個，但 2 個就已經是菜單。
6. **格子封面**：前九格縮成小圖看。短影音封面要挑過，不是隨便第一格；封面放四個字，整個格子一眼就讀得懂。

## 交出來
- 分數表。
- 改寫內容：照先後順序，每段都能直接複製，先跑 `去AI味.py`。
- 改完重新打分，誠實給前後差距。改完是 84 分不是 98 分，就說 84，並說剩下的分數需要什麼。通常是格子、每天發限時動態的習慣、還沒拍的置頂貼文，這些都不是改文字能解決的。

**總監和主管各有自己的帳號，分開健檢、分開存。**

這個功能不會改 IG 上的任何東西，每一欄由對方自己改。
