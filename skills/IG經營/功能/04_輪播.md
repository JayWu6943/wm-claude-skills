# 輪播：一個想法拆成幾頁，讓人一頁一頁滑

輪播是 IG 上停留最久的格式，因為「滑」算一次互動，往下捲不算。輪播還有第二次機會：沒互動的人，IG 可能從第二頁開始再給他看一次，所以**第二頁也要能單獨成立**。

## 什麼時候用輪播，不用短影音
- **用輪播**：想法有順序、需要重看。例如步驟、有幾個部分的方法、前後對比、值得截圖的清單。
- **用短影音**：想法有動作、有臉、成果要「看到發生」。攝影的前後對比，兩種都適合。
- 想法只有一句話：兩種都不適合，交給「短影音腳本」寫成一支，並直說。

## 結構：6～10 頁
上限 20 頁，20 頁幾乎就是沒人看完的書；少於 5 頁，人還沒開始滑就結束了。
```
第 1 頁       封面      開頭，8 個字以內，縮成小圖也看得清楚；下面一行寫承諾
第 2 頁       為什麼重要 一句話。這頁也是第二個封面，不能只是鋪陳
第 3～N 頁    一頁一個重點：標題 3～10 字，下面最多 40 個字；需要一段話就拆成兩頁
倒數第 2 頁   總整理    整篇變成一張清單，這是會被截圖、轉傳的那頁
最後一頁      行動呼籲   一個：收藏、留言關鍵字、追蹤
```

## 每頁文字的規則
- **封面決定八成結果。** 8 個字、字要大。封面沒人滑，後面做再好都沒用。
- **照個人頁的格子裁切來設計。** 做 1080×1350，封面的字放在正中間，四邊各留 120 像素空白，裁切比例怎麼變都不怕。
- **頁數要標出來（3/8）**：看得到終點，看完的人比較多。
- **沒有一頁是一整段文字。** 40 個字講不完就拆頁。
- **總整理那頁要能單獨看懂。** 被轉傳是最強的訊號。
- **每頁小小放帳號名稱**（右下角）：截圖傳出去時，別人知道從哪來的。
- **封面至少要寫替代文字。**

## 做圖檔
IG 要 1080×1350（4:5），JPG 或 PNG，最多 20 張。用 HTML 做：
- 每頁一個區塊，寬 1080、高 1350，用無頭瀏覽器（Chrome headless）轉成圖片。
- 只用一個重點色。字不要小於 32 像素，手機上看大約只有實際大小的三分之一。
- 用薇萌的品牌：深色 #1A1916、品牌金 #C9A77C、思源黑體。不要自己發明配色。

## 交出來
1. **先給每頁文字**：用編號清單，10 秒看得完，可以先改，確認後才做圖。
2. **貼文文字**：輪播用「貼文文字」的任務 B，因為封面只有 8 個字，貼文文字要幫忙抓人。
3. 先跑 `去AI味.py` 檢查文字。
4. **對方同意文字後才做圖。**

```
輪播 · 8 頁
1 封面   三萬塊的教訓
         我現在每份合約都會加的一句話
2 重要   我交了照片，客人九天後要求退款
3        那句話是什麼
         交件就付款，不是滿意才付款
...
7 總整理  四句話，照順序
8 行動    留言「合約」，我把完整條款傳給你
貼文文字：任務 B，第一行是開頭，一個行動呼籲，3 個標籤
```

不代發，對方自己上傳。
