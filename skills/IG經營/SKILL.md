# IG 經營工具箱

中文化自 Jake Schincariol 的 instagram-agent-skill（MIT 授權，見 `授權.txt`），改成適合薇萌和台灣的版本；「去 AI 味」改成認得繁體中文 AI 口吻的版本。

全程繁體中文、台灣口語，不講術語；不要一直問授權。

## 三條不能破的規則
1. **只寫，不發。** 這裡的每個功能都只產生草稿。發文、留言、私訊一律由總監或主管自己按，絕不代為登入 IG、絕不自動發送。自動化大量留言或私訊違反 IG 規定，會被限制帳號。
2. **不編造。** 不編客人、數字、成果。需要數字但不知道，就寫 `{{你的數字}}` 並標出來。客人案例要先確認客人同意。
3. **總監和主管分開。** 兩個人的語氣、紀錄、參考清單、週計畫都分開存，不混用。開始前先確認這次是誰的帳號。
   - 資料放在 `~/.claude/instagram/總監/` 或 `~/.claude/instagram/主管/`
   - 每人有：`語氣.md`（照 `語氣設定範本.md` 填）、`參考清單.md`（爆款研究產生）、`發文紀錄.md`、`週計畫.md`

保險、理財的內容：提醒發布前自己再確認說法，不能寫保證報酬。

**找員工**：用 Agent 工具交給上面那位員工，交代時附上那份功能說明和這人的 `語氣.md`。員工還沒裝就照 `/員工` 的流程加。

**沒帶文字時（只打 /IG經營）**：用 AskUserQuestion 問一題（header：「IG 經營」）：「今天要做哪一件？」選項：
1. 寫短影音腳本
2. 這週要發什麼（每週計畫）
3. 個人檔案健檢
4. 其他（貼文、輪播、限動、留言、私訊、一變多、檢討、爆款研究、去 AI 味）

選 4 再用一句話問是哪一個。

## 這個資料夾裡的小程式（都在電腦上跑、不連網路、不用錢）

| 程式 | 做什麼 |
| --- | --- |
| `開頭評分.py` | 中文開頭五面向評分，一次比較好幾個開頭，並標出用了哪個公式 |
| `秒數表.py` | 中文腳本每句幾秒，抓出太長、沒具體內容、沒呼應開頭的地方（總監每秒約 4.8 字） |
| `貼文檢查.py` | 貼文前段框起來給你看，檢查標籤、行動呼籲、搜尋詞 |
| `爆款排名.py` | 用「比帳號平常高幾倍」排名蒐集到的影片，產生參考清單 |
| `開頭公式.json` | 26 種開頭公式，每個有句型、薇萌範例、畫面字、地雷 |
| `個人檔案評分表.json` | 個人檔案 12 項、滿分 100 的評分標準 |
| `去AI味.py`、`中文AI口吻.json` | 找出繁體中文文案裡的 AI 口吻，能修的自動修，給「像人寫的」分數 |
| `語氣設定範本.md` | 每個人的語氣設定（總監、主管各一份） |

## 結尾
做完用一句話提醒下次可以直接打的指令，例如「下次可以直接打 `/IG經營 寫腳本：形象照不是拍給自己看的`」。
