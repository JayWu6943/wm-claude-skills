# 做影片（OpenMontage）

老闆不懂程式，全程繁體中文；不要一直問授權。只有兩個地方要停下來等老闆：
1. 分鏡完成時，先給老闆看。
2. 要花錢時，先問老闆。

## 1. 準備 OpenMontage（第一次會比較久，先告訴老闆「大約要等 5～10 分鐘」）

1. 先找 `$HOME/OpenMontage` 或 `/home/user/OpenMontage`，有就用。
2. 沒有的話，**只能**從官方下載：
   - `git clone https://github.com/calesthio/OpenMontage`，再進資料夾跑 `make setup`。
   - 網路上有冒名的版本會附 .exe、.7z「安裝檔」，那些是假的，絕對不要下載或執行。
3. 開工前先讀它的 `AGENT_GUIDE.md` 和 `CLAUDE.md`，照它的流程走。

## 2. 問清楚要什麼

老闆已經說清楚的就不要再問。沒說的，用**一次** AskUserQuestion 問完，最多 4 題：

| header | 問題 | 選項 |
| --- | --- | --- |
| 片型 | 這支是什麼片？ | 品牌形象短片／服務介紹／活動宣傳／教學說明 |
| 尺寸 | 要放哪裡？ | 直式 9:16（IG、抖音、限動）／橫式 16:9（YouTube、官網）／方形 1:1（貼文） |
| 長度 | 多長？ | 15 秒左右／30 秒左右／60 秒左右 |
| 素材 | 用什麼照片？ | 官網現有的照片／我等一下上傳／不用照片，做純字卡 |

素材的處理：
- **選「官網現有的照片」：** 從官網專案的 `public/` 挑合適的照片，例如形象照、標誌、作品照。
- **選「我等一下上傳」：** 等老闆上傳。
- **最後：** 把素材複製到 OpenMontage 的 `inputs/<片名英文代號>/`。

字卡文字老闆沒給的話，依薇萌 WM Group（形象照、品牌影像、保險理財、行銷顧問）的品牌語氣先擬好，放進分鏡給他看。

## 3. 製作

1. **一定要走 OpenMontage 的製作流程：**
   - 照它的 AGENT_GUIDE 一關一關做：發想 → 腳本 → 分鏡 → 素材 → 剪輯 → 合成 → 輸出。
   - 在 `projects/<片名英文代號>/` 留下各階段的紀錄。
   - 每支新影片都開一個新的專案資料夾，不要拿舊專案改，以免覆蓋之前的成片。老闆明說「改上次那支」才改舊的。
   - **不可以**跳過 OpenMontage，自己用 ffmpeg 或其他方式拼一支片交差。老闆要的就是這個「影片製作團隊」。
2. **選流程：** 照片加字卡的片，選 `pipeline_defs/hybrid.yaml`。其他片型，照 AGENT_GUIDE 挑最合適的流程。
3. **預設不花錢：**
   - OpenMontage 本身是免費的，用它內建的照片動態、字卡、轉場、字幕、合成（例如 Remotion）都不用錢。
   - 「不花錢」指的是不呼叫付費的外部服務：AI 生圖、AI 生影片、AI 配音。
   - 要用這些付費服務，先估好大概多少錢，問老闆同意才用。
4. **分鏡完成時停下來：** 用條列給老闆看「幾秒到幾秒：畫面＋字卡」，再用 AskUserQuestion 問（header：「分鏡」）。選項：
   - 繼續製作
   - 我要修改
5. **繼續：** 剪輯、合成、輸出。

## 4. 檢查與交付

1. **檢查：**
   - 抽 3～4 格畫面看：繁體中文不能缺字，字不能被切掉，字和人臉不能重疊。
   - 有問題就修好重新輸出。
2. **交付：** 用 SendUserFile 把成片傳給老闆。
3. **回報：** 尺寸、長度、花了多少錢（外部服務費＋大約的 Claude 用量）。
4. **最後一句：** 「要改哪裡直接說，例如『第二段字放大』」。

## 不要做

- 不從官方以外的地方下載 OpenMontage 或任何「安裝檔」。
- 不在老闆沒同意的情況下用付費服務。
- 不把 OpenMontage 的專案檔、程式改動上傳到官網的 GitHub。影片只交付成品。
